# Capitole du Libre — Brand

Logos, icons and communication material for
[Capitole du Libre](https://capitoledulibre.org), the annual free
software and free culture event held in Toulouse.

## Repository layout

```
brand/
├── logo/        # main logos (SVG, PDF, PNG, EPS — horizontal and vertical)
├── icon/        # icons and favicons (SVG, PNG)
├── print/       # multi-year print templates (photobooth kakemono, plan kakemono, masks)
├── social/      # multi-year social templates (Twitter banner template)
└── video/       # multi-year video assets (animated explainer)
editions/
└── <year>/      # posters, social thumbnails, badges, signage, etc. per edition
sources/         # editable source files (.afdesign, .ai, .xcf, ...)
```

See [`CONTRIBUTING.md`](CONTRIBUTING.md) for naming conventions and
how to add new material.

## Brand colors

### Primary (orange)

| Name         | Hex       | Usage                                  |
|--------------|-----------|----------------------------------------|
| CdL orange   | `#d03d00` | Primary color, calls to action, links  |
| Light orange | `#ff6b35` | Hover state, secondary accents         |
| Dark orange  | `#a33000` | Active state, shadows                  |

### Secondary

| Name         | Hex       | Usage                              |
|--------------|-----------|------------------------------------|
| Deep blue    | `#1a365d` | Main text, headers                 |
| Medium blue  | `#2c5282` | Secondary text, links              |
| Golden yellow| `#f6ad55` | Highlights, badges                 |

### Neutral

| Name         | Hex       | Usage                              |
|--------------|-----------|------------------------------------|
| Warm gray    | `#4a5568` | Body text                          |
| Light gray   | `#e2e8f0` | Borders, surfaces                  |
| Off-white    | `#fafafa` | Page background                    |

## Typography

- **Ubuntu** (400, 500, 700) — headings, navigation, buttons
- **Ubuntu Mono** (400, 700) — code, technical data
- **Source Sans 3** (400, 600) — body text (neutral alternative)
