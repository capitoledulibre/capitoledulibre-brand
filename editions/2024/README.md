## Notes

This edition was co-hosted with MiniDebConf (visible in the badge
template `print/badge-cdl-2024.svg` and in the
`social/cdl-and-minidebconf-2024.*` announcement).

No traditional large-format poster was produced this year — the
file `poster/affiche-linux-pratique-cdl-2024.*` is an advertisement
that ran in the *Linux Pratique* magazine.

The `signage/kakemono-plan-patch{1,2}-2024.pdf` files are correction
patches that were printed and applied on top of the plan kakemono
to fix errors.
